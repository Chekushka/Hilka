Порівняння дає відповідь «так» чи «ні» — значення логічного типу `bool`: `True` або `False`.

```python
print(5 > 3)    # True
print(2 == 7)   # False
```

Операції відношення: `>`, `<`, `>=`, `<=`, `==` (дорівнює — два знаки!), `!=` (не дорівнює).

Логічні оператори поєднують кілька умов:

- `and` — «і»: `True`, коли правдиві **обидві** частини
- `or` — «або»: `True`, коли правдива **хоча б одна**
- `not` — «не»: перевертає значення

```python
age = 13
print(age >= 12 and age <= 15)   # True
print(age < 6 or age > 60)       # False
print(not age > 10)              # False
```

Логічний вираз можна просто вивести — і if для цього не потрібен.
