Проєкт: **розв'язувач квадратних рівнянь** `ax² + bx + c = 0`. По кроку на завдання.

Скільки коренів — каже **дискримінант**:

```python
d = b * b - 4 * a * c
```

---

- `D > 0` — два корені
- `D = 0` — один корінь
- `D < 0` — коренів немає

---

```guess
a = 1
b = 2
c = 1
print(b * b - 4 * a * c)
-- *
0
--
8
--
-8
-- чому
4 − 4 = 0: один корінь.
```

---

Два корені:

```notes
import math

x1 = (-b - math.sqrt(d)) / (2 * a)   # дужки навколо 2 * a!
x2 = (-b + math.sqrt(d)) / (2 * a)
```

---

```guess
a = 2
print(8 / 2 * a)
print(8 / (2 * a))
-- *
8.0
2.0
--
2.0
2.0
--
8
2
-- чому
Без дужок — зліва направо: 8 / 2 = 4.0, × 2 = 8.0. З дужками: 8 / 4 = 2.0.
```

---

```remember
`d = b*b - 4*a*c` — дискримінант
`/ (2 * a)` — дільник у дужках
D > 0 — два корені, D = 0 — один, D < 0 — жодного.
```
