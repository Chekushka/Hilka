Час для першого проєкту: програми, яка розв'язує **квадратні рівняння**. Будуватимемо її по кроках, і кожне завдання — один крок.

Квадратне рівняння має вигляд `ax² + bx + c = 0`. Числа `a`, `b`, `c` — **коефіцієнти**. Скільки в рівняння коренів, показує **дискримінант**:

```python
d = b * b - 4 * a * c
```

- `D > 0` — два корені
- `D = 0` — один корінь
- `D < 0` — коренів немає

Коли коренів два, їх знаходять так:

```python
import math

x1 = (-b - math.sqrt(d)) / (2 * a)
x2 = (-b + math.sqrt(d)) / (2 * a)
```

Зверни увагу на дужки навколо `2 * a`: без них Python поділить на 2, а тоді **помножить** на `a`.
