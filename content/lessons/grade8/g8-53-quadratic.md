Час для першого проєкту: програми, яка розв'язує **квадратні рівняння**. Будуватимемо її по кроках, і кожне завдання — один крок.

Квадратне рівняння має вигляд `ax² + bx + c = 0`. Числа `a`, `b`, `c` — **коефіцієнти**. Скільки в рівняння коренів, показує **дискримінант**:

```python
d = b * b - 4 * a * c
```

- `D > 0` — два корені
- `D = 0` — один корінь
- `D < 0` — коренів немає

---

```guess
a = 1
b = 2
c = 1
print(b * b - 4 * a * c)
-- *
0
--
8
--
-8
-- чому
2 · 2 − 4 · 1 · 1 = 4 − 4 = 0. Дискримінант дорівнює нулю — у рівняння один корінь.
```

---

Коли коренів два, їх знаходять так:

```python
import math

x1 = (-b - math.sqrt(d)) / (2 * a)
x2 = (-b + math.sqrt(d)) / (2 * a)
```

Зверни увагу на дужки навколо `2 * a`: без них Python поділить на 2, а тоді **помножить** на `a`.

```guess
a = 2
print(8 / 2 * a)
print(8 / (2 * a))
-- *
8.0
2.0
--
2.0
2.0
--
8
2
-- чому
Без дужок Python рахує зліва направо: 8 / 2 = 4.0, потім 4.0 · 2 = 8.0. З дужками — 8 / 4 = 2.0. А `/` завжди дає дробове число.
```

```remember
`D = b² − 4ac`: більше нуля — два корені, нуль — один, менше — жодного.
Дільник беремо в дужки: `/ (2 * a)`.
```
