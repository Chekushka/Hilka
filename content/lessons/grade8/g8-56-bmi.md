Проєкт: калькулятор **ІМТ** — індексу маси тіла (шкала для дорослих).

**ІМТ = маса / зріст²**, зріст — у **метрах**.

```notes
weight = float(input())       # кг
height = float(input())       # м
bmi = weight / height ** 2    # ** — першим
print(round(bmi, 1))          # одна цифра після крапки
```

---

```guess
weight = 50
height = 1.6
print(round(weight / height ** 2, 1))
-- *
19.5
--
31.2
--
19.53
-- чому
1.6² = 2.56, 50 / 2.56 ≈ 19.53, `round(…, 1)` → 19.5.
```

---

Зріст у сантиметрах — поділи на 100:

```guess
height = 165 / 100
print(height)
-- *
1.65
--
165
--
1
-- чому
`/` дає дробове. `//` дало б 1 — і ІМТ був би хибний.
```

---

Категорію шукають через `if … elif … else` — від меншої межі до більшої.

```remember
`weight / height ** 2` — ІМТ
`round(x, 1)` — одна цифра після крапки
`float(input())` — дробове число
```
