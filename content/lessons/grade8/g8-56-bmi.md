Другий проєкт — калькулятор **індексу маси тіла** (ІМТ). Лікарі використовують його для дорослих; для підлітків шкала інша, тож у задачах ми рахуємо ІМТ для дорослих.

ІМТ — це маса в кілограмах, поділена на квадрат зросту в **метрах**:

```python
weight = float(input("Маса, кг: "))
height = float(input("Зріст, м: "))
bmi = weight / height ** 2
print(round(bmi, 1))
```

---

```guess
weight = 50
height = 1.6
print(round(weight / height ** 2, 1))
-- *
19.5
--
31.2
--
19.53
-- чому
`**` виконується першим: 1.6² = 2.56, і 50 / 2.56 ≈ 19.53. `round(…, 1)` лишає одну цифру після крапки — 19.5.
```

---

Маса і зріст бувають дробовими, тому їх читаємо через `float()`. Якщо користувач вводить зріст у сантиметрах, його спершу ділять на 100.

```guess
height = 165 / 100
print(height)
-- *
1.65
--
165
--
1
-- чому
`/` — звичайне ділення з дробовою частиною. Ціле ділення `//` дало б 1, і ІМТ вийшов би зовсім неправильним.
```

---

Щоб назвати категорію, ІМТ порівнюють з межами по черзі, від меншої до більшої, через `if … elif … else`.

```remember
ІМТ = маса / зріст²: `weight / height ** 2`, зріст — у метрах.
Сантиметри ділимо на 100 звичайним `/`.
```
