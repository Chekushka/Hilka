Тепер з'єднаємо кроки в одну програму — **розв'язувач рівнянь**. Вона читає коефіцієнти, рахує дискримінант і вибирає одну з трьох гілок:

```python
d = b * b - 4 * a * c
if d < 0:
    print("коренів немає")
elif d == 0:
    print(-b / (2 * a))
else:
    print((-b - math.sqrt(d)) / (2 * a))
    print((-b + math.sqrt(d)) / (2 * a))
```

`math.sqrt` не вміє брати корінь з від'ємного числа — програма впаде з помилкою. Тому корінь рахуємо лише в тій гілці, де `D` точно не від'ємний.

Коли перевіряєш програму, добирай такі дані, щоб спрацювала **кожна** гілка: одне рівняння з двома коренями, одне з одним і одне без коренів. І не лише з `a = 1` — деякі помилки видно тільки при інших `a`.
