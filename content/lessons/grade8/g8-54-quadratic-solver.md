Усе разом — **три гілки**:

```notes
d = b * b - 4 * a * c
if d < 0:
    print("коренів немає")
elif d == 0:
    print(-b / (2 * a))                    # один корінь
else:
    print((-b - math.sqrt(d)) / (2 * a))   # два корені
    print((-b + math.sqrt(d)) / (2 * a))
```

`math.sqrt` від **від'ємного** — помилка. Тому корінь — лише там, де D ≥ 0.

Перевір **кожну** гілку: два корені, один, жодного. І не лише з `a = 1`.

```remember
`math.sqrt(d)` — лише коли d не від'ємне
Перевір кожну гілку — і різні a.
```
