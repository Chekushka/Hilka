`while` повторює, **доки** умова правдива:

```guess
x = 1
while x < 100:
    x = x * 2
print(x)
-- *
128
--
64
--
100
-- чому
2, 4, … 64 — ще менше 100, тож ще раз: 128. Тепер стоп.
```

---

Коли невідомо, скільки повторів, — читаємо, **доки не введуть** особливе слово:

```notes
word = input()              # перше — до циклу
count = 1
while word != "стоп":
    word = input()          # наступні — всередині
    count = count + 1
print(count)
```

---

```remember
`while умова:` — доки правда
Перше значення — до циклу, наступні — всередині.
Нічого не змінюється — цикл не скінчиться.
```
