Цикл `while` повторює команди, **доки** умова правдива:

```python
x = 1
while x < 100:
    x = x * 2
print(x)   # 128
```

`while` особливо зручний, коли наперед невідомо, скільки разів повторювати, — наприклад, коли програма читає дані, доки не введуть щось особливе:

```python
word = input()
count = 1
while word != "стоп":
    word = input()
    count = count + 1
print(count)
```

Зверни увагу: перше значення читаємо **до** циклу, а наступні — всередині. Якщо всередині циклу нічого не змінюється, умова ніколи не стане хибною, і програма повторюватиметься без кінця.
