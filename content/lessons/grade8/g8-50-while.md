Цикл `while` повторює команди, **доки** умова правдива:

```guess
x = 1
while x < 100:
    x = x * 2
print(x)
-- *
128
--
64
--
100
-- чому
`x` подвоюється: 2, 4, 8, 16, 32, 64. 64 ще менше за 100, тож цикл подвоює ще раз — до 128. Тепер умова хибна.
```

---

`while` особливо зручний, коли наперед невідомо, скільки разів повторювати, — наприклад, коли програма читає дані, доки не введуть щось особливе:

```python
word = input()
count = 1
while word != "стоп":
    word = input()
    count = count + 1
print(count)
```

Зверни увагу: перше значення читаємо **до** циклу, а наступні — всередині. Якщо всередині циклу нічого не змінюється, умова ніколи не стане хибною, і програма повторюватиметься без кінця.

```remember
`while` повторює, доки умова правдива.
Перше значення читаємо до циклу, наступні — всередині.
Усередині має щось змінюватися, інакше цикл не закінчиться.
```
