**Коментар** — пояснення для людей. Усе після `#` Python **пропускає**.

```python
# Обчислюємо вартість покупки
price = float(input())   # ціна одного товару
count = int(input())     # кількість
print(price * count)
```

Добрий коментар пояснює **навіщо**, а не переказує код.

---

`#` перед рядком — тимчасово «вимкнути» його. Так шукають помилки.

```guess
print("# 1")
# print(2)
print(3)  # три
-- *
# 1
3
--
# 1
2
3
--
1
3
-- чому
`#` у лапках — просто символ. Рядок з `#` на початку пропускається.
```

---

```remember
`# текст` — коментар, Python його пропускає
`"#"` — у лапках це просто символ
```
