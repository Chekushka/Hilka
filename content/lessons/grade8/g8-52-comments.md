**Коментар** — це пояснення в коді для людей. Усе, що стоїть після `#`, Python пропускає:

```python
# Обчислюємо вартість покупки
price = float(input())   # ціна одного товару
count = int(input())     # кількість
print(price * count)
```

Коментарі допомагають зрозуміти програму тобі самому через тиждень, однокласнику чи вчителю. Добрий коментар пояснює, **навіщо** щось робиться, а не повторює код словами.

Ще один прийом: рядок можна тимчасово «вимкнути», поставивши перед ним `#`. Так роблять, коли шукають помилку. Тільки не забудь потім прибрати `#` — інакше команда так і не виконається.

Зверни увагу: `#` у лапках — це просто символ тексту, а не коментар: `print("# 1")` виведе `# 1`.
