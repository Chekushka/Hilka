**Перевірка кореня**: підстав `x` — ліва частина має дати **0**.

```guess
a = 1
b = -5
c = 6
x = 2
print(a * x * x + b * x + c == 0)
-- *
True
--
False
--
0
-- чому
4 − 10 + 6 = 0, тож `== 0` — правда.
```

---

**a = 0** — рівняння лінійне: `bx + c = 0`. Формула з D ділить на нуль, тому цей випадок — **першим**:

```notes
if a == 0:
    print(-c / b)    # лінійне рівняння
else:
    ...              # розв'язувач із дискримінантом
```

---

```remember
`== 0` — x є коренем
`a == 0` — перевірити першим, тоді x = -c / b
```
