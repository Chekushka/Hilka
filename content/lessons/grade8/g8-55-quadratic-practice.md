Удосконалюємо розв'язувач.

**Перевірка кореня.** Щоб переконатися, що число `x` — корінь, його підставляють у рівняння. Якщо ліва частина дорівнює нулю — це корінь:

```python
print(a * x * x + b * x + c == 0)
```

**Випадок a = 0.** Тоді `x²` зникає і рівняння стає лінійним: `bx + c = 0`, його корінь `x = -c / b`. Формула з дискримінантом тут не працює — вона ділить на `2a`, тобто на нуль. Тому цей випадок перевіряють **першим**:

```python
if a == 0:
    print(-c / b)
else:
    # тут — розв'язувач із дискримінантом
    ...
```
