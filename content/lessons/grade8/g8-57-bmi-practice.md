`/` і `*` — **зліва направо**:

```notes
weight / height * height     # знову маса!
weight / (height * height)   # ІМТ
weight / height ** 2         # теж ІМТ
```

---

```guess
weight = 64
height = 2
print(weight / height * height)
print(weight / height ** 2)

-- чому
64 / 2 × 2 = 64.0. А `**` першим: 64 / 4 = 16.0.
```

---

Формулу можна розвернути: **маса = ІМТ · зріст²**.

Кілька людей — цикл `for`: всередині читання, обчислення, перевірка.

```remember
`a / b * b` — зліва направо, це знову a
`**` — виконується першим
```
