Удосконалюємо калькулятор ІМТ.

Будь уважним із порядком дій. `/` і `*` мають однаковий пріоритет, і Python виконує їх **зліва направо**:

```python
weight / height * height     # це (weight / height) * height — знову маса!
weight / (height * height)   # а це ІМТ
weight / height ** 2         # і це ІМТ: ** виконується першим
```

Формулу можна «розвернути»: якщо ІМТ = маса / зріст², то маса = ІМТ · зріст². Так можна знайти, яка маса відповідає будь-якому значенню ІМТ.

А щоб обробити дані кількох людей, знадобиться цикл `for`, усередині якого — читання, обчислення і перевірка.
