Команда розгалуження `if` дає програмі вибір: виконати одні команди або інші.

```python
score = int(input())
if score >= 60:
    print("склав")
else:
    print("не склав")
```

Після умови — **двокрапка**. Команди всередині `if` і `else` пишуться з **відступом** у чотири пробіли: саме відступ показує, що належить до гілки.

---

```guess
score = 60
if score >= 60:
    print("склав")
else:
    print("не склав")
-- *
склав
--
не склав
--
склав
не склав
-- чому
`>=` означає «більше або дорівнює», тож 60 підходить. Виконується лише одна з гілок.
```

---

Коли варіантів більше двох, між ними ставлять `elif`:

```python
t = int(input())
if t <= 0:
    print("лід")
elif t >= 100:
    print("пара")
else:
    print("вода")
```

Умови перевіряються згори донизу, і виконується лише **перша** правдива гілка.

```guess
t = 100
if t <= 0:
    print("лід")
elif t >= 100:
    print("пара")
else:
    print("вода")
-- *
пара
--
вода
--
вода
пара
-- чому
100 ≤ 0 — ні. 100 ≥ 100 — так, тож «пара». До `else` черга вже не доходить.
```

```remember
Після умови — двокрапка, у гілці — відступ у 4 пробіли.
Виконується лише перша правдива гілка.
```
