`if` дає **вибір**:

```notes
score = int(input())
if score >= 60:          # двокрапка
    print("склав")       # відступ 4 пробіли
else:
    print("не склав")
```

---

```guess
score = 60
if score >= 60:
    print("склав")
else:
    print("не склав")
-- *
склав
--
не склав
--
склав
не склав
-- чому
`>=` — «більше **або дорівнює»**: 60 підходить.
```

---

Три й більше варіантів — `elif`. Виконується лише **перша** правдива гілка.

```guess
t = 100
if t <= 0:
    print("лід")
elif t >= 100:
    print("пара")
else:
    print("вода")
-- *
пара
--
вода
--
вода
пара
-- чому
100 ≤ 0 — ні. 100 ≥ 100 — так. До `else` черга не дійшла.
```

---

```remember
`if умова:` — двокрапка, далі відступ
`>=` — більше або дорівнює
`elif` — ще один варіант
```
