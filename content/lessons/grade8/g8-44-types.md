**Змінна** — це ім'я, під яким програма зберігає значення. Значення кладуть у змінну знаком `=`:

```python
city = "Житомир"
students = 28
height = 1.62
```

У кожного значення є **тип**:

- `int` — ціле число: `28`, `-5`
- `float` — дробове число, з **крапкою**: `1.62`, `4.0`
- `str` — рядок, тобто текст у лапках: `"Житомир"`, `"28"`
- `bool` — логічне значення: `True` або `False`

Тип важливий: `"5" + "3"` — це `"53"` (рядки склеюються), а `5 + 3` — це `8`. Дізнатися тип допомагає `type()`, а перетворити — `int()`, `float()`, `str()`:

```python
text = "12"
number = int(text)
print(number * 2)   # 24
print(text * 2)     # 1212
```
