**Змінна** — ім'я для значення. Значення кладуть знаком `=`.

```python
city = "Житомир"
students = 28
height = 1.62
```

---

Типи значень:

- `int` — ціле число: 28, -5
- `float` — дробове, з крапкою: 1.62
- `str` — текст у лапках: "28"
- `bool` — True або False

---

Тип вирішує, що зробить оператор. Пройди по рядках — стеж за лапками:

```memory
a = 5
> a = 5
b = "5"
> b = "5"
c = a * 2
> c = 10
d = b * 2
> d = "55"
e = a / 2
> e = 2.5
```

---

```guess
print("5" + "3")
print(5 + 3)
-- *
53
8
--
8
8
--
53
53
-- чому
Рядки `+` склеює, числа — додає.
```

---

Перетворення: `int()`, `float()`, `str()`.

```guess
text = "12"
print(text * 2)
print(int(text) * 2)
-- *
1212
24
--
24
24
--
1212
1212
-- чому
Рядок × 2 — повторюється. Після `int()` — звичайне число.
```

---

```remember
`int` — ціле число
`float` — дробове число
`str` — текст
`"5" + "3"` — склеїти: 53
```
