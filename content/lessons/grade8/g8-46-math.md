Арифметичні оператори Python:

- `+`, `-`, `*` — додавання, віднімання, множення: `7 * 2` дає `14`
- `/` — ділення, результат завжди дробовий: `7 / 2` дає `3.5`
- `//` — ціла частина від ділення: `7 // 2` дає `3`
- `%` — остача від ділення: `7 % 2` дає `1`
- `**` — степінь: `2 ** 3` дає `8`

Для складніших обчислень є модуль `math`. Його підключають командою `import`:

```python
import math

print(math.sqrt(16))     # квадратний корінь: 4.0
print(math.pi)           # число π
print(math.ceil(2.1))    # округлення вгору: 3
print(round(3.14159, 2)) # round — без math: 3.14
```
