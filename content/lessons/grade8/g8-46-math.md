Оператори:

- `+` `-` `*` — плюс, мінус, множення
- `/` — ділення, дробове: 7 / 2 → 3.5
- `//` — ціла частина: 7 // 2 → 3
- `%` — остача: 7 % 2 → 1
- `**` — степінь: 2 ** 3 → 8

---

```guess
print(17 // 5)
print(17 % 5)
-- *
3
2
--
3.4
2
--
2
3
-- чому
5 вміщається в 17 тричі (`//`), лишається 2 (`%`).
```

---

Модуль `math` — для складнішого:

```notes
import math

print(math.sqrt(16))      # корінь: 4.0
print(math.ceil(2.1))     # вгору: 3
print(round(3.14159, 2))  # round — без math
```

---

```guess
import math
print(math.sqrt(9))
-- *
3.0
--
3
--
81
-- чому
`sqrt` — корінь: 3 · 3 = 9. Результат завжди дробовий.
```

---

```remember
`//` — ціла частина
`%` — остача
`**` — степінь
`math.sqrt(x)` — квадратний корінь
```
