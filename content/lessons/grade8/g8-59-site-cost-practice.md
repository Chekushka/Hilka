Кілька `if` підряд: кожен бачить ціну такою, якою її **залишили** попередні рядки.

```guess
price = 15000
if price > 20000:
    price = price * 0.9
price = price * 1.5
print(price)
-- *
22500.0
--
20250.0
--
15000
-- чому
Знижку перевірили, коли ціна була 15000, — і не дали. Порядок важливий.
```

---

Округлення:

```notes
import math

print(round(7.5))       # до найближчого
print(math.ceil(7.5))   # завжди вгору
print(4500 // 800)      # скільки разів 800 у 4500
```

---

```guess
import math
print(math.ceil(7.1))
print(4500 // 800)
-- *
8
5
--
7
5
--
8
5.625
-- чому
`ceil` — завжди вгору, навіть 7.1. `//` — лише ціла частина.
```

---

```remember
`math.ceil(x)` — округлити вгору
`a // b` — скільки разів b вміщається в a
Порядок if змінює результат.
```
