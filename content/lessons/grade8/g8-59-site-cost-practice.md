Удосконалюємо калькулятор сайту.

Коли програма складається з кількох `if` підряд, **порядок** має значення. Кожен `if` бачить значення змінної таким, яким його залишили попередні рядки. Якщо перевірити знижку раніше, ніж додати терміновість, програма вирішить про знижку за неповною ціною.

Для округлення стануть у пригоді:

```python
import math

print(round(7.5))       # до найближчого цілого
print(math.ceil(7.5))   # завжди вгору: 8
print(4500 // 800)      # скільки разів 800 поміщається в 4500: 5
```

Не забувай про межові випадки: що, якщо бюджету не вистачає навіть на базову ціну?
