`input()` зупиняє програму і чекає, доки користувач щось введе. У дужках можна написати підказку:

```python
name = input("Як тебе звати? ")
print("Привіт,", name)
```

**Важливо:** `input()` завжди повертає **текст**, навіть якщо ввели число. Щоб рахувати, текст треба перетворити:

```python
age = int(input("Скільки тобі років? "))
height = float(input("Твій зріст у метрах: "))
print("Наступного року тобі буде", age + 1)
```

`print()` може вивести кілька значень через кому — між ними буде пробіл. Інший роздільник задає `sep`:

```python
print(29, 9, 2026, sep=".")   # 29.9.2026
```

Коли ти натискаєш **Перевірити**, програму запускають кілька разів із різними введеннями — так само, як учитель перевіряв би її вручну.
