`input()` зупиняє програму і чекає, доки користувач щось введе. У дужках можна написати підказку:

```python
name = input("Як тебе звати? ")
print("Привіт,", name)
```

---

**Важливо:** `input()` завжди повертає **текст**, навіть якщо ввели число. Щоб рахувати, текст треба перетворити:

```python
age = int(input("Скільки тобі років? "))
height = float(input("Твій зріст у метрах: "))
print("Наступного року тобі буде", age + 1)
```

Ось що буває, коли забути про перетворення:

```guess
age = "13"
print(age + "1")
-- *
131
--
14
--
13 1
-- чому
`age` — текст, тож `+` склеює рядки. Щоб отримати 14, потрібне число: `int(age) + 1`.
```

---

`print()` може вивести кілька значень через кому — між ними буде пробіл. Інший роздільник задає `sep`:

```python
print(29, 9, 2026, sep=".")   # 29.9.2026
```

```guess
print("a", "b", "c")
print("a", "b", "c", sep="-")
-- *
a b c
a-b-c
--
abc
a-b-c
--
a b c
a - b - c
-- чому
Без `sep` між значеннями стоїть один пробіл. З `sep="-"` замість пробілу стоїть саме дефіс — і нічого більше.
```

---

Коли ти натискаєш **Здати**, програму запускають кілька разів із різними введеннями — так само, як учитель перевіряв би її вручну.

```remember
`input()` завжди дає текст — для чисел `int()` чи `float()`.
`print(a, b)` виводить через пробіл, `sep="…"` задає інший роздільник.
```
