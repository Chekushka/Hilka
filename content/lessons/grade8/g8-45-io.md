`input()` **чекає**, доки користувач щось введе:

```notes
name = input("Як тебе звати? ")   # підказка в дужках
print("Привіт,", name)
```

---

`input()` завжди дає **текст** — навіть коли ввели число.

```guess
age = "13"
print(age + "1")
-- *
131
--
14
--
13 1
-- чому
`age` — текст, тож `+` склеює. Для числа: `int(age) + 1`.
```

---

Числа з введення:

```notes
age = int(input())        # ціле
height = float(input())   # дробове
print(age + 1)
```

---

Кілька значень через кому — **пробіл** між ними. Інший роздільник — `sep`.

```guess
print("a", "b", "c")
print("a", "b", "c", sep="-")
-- *
a b c
a-b-c
--
abc
a-b-c
--
a b c
a - b - c
-- чому
`sep="-"` замінює пробіл саме на дефіс — і нічого більше.
```

---

«Здати» запускає програму **кілька разів** з різними введеннями — як учитель вручну.

```remember
`input()` — завжди текст
`int(input())` — зчитати число
`sep="."` — інший роздільник у print
```
