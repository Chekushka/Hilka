Комп'ютер розуміє лише машинні команди. Python-програму йому **перекладає транслятор**.

Python — **інтерпретатор**: перекладає рядок і одразу виконує, потім наступний.

```notes
print("Привіт!")                      # виконується першим
print("Я виконую команди по черзі")   # потім цей
```

Де писати програми:

- `Hilka` — тут, у браузері: редактор, «Запустити», виведення
- `IDLE` — на комп'ютерах у класі: файл `.py`, запуск клавішею F5

---

Помилка — це нормально. Транслятор покаже **рядок**: виправ і запусти знову.

```remember
Інтерпретатор — виконує рядки по черзі, згори донизу.
`F5` — запуск програми в IDLE
`"2 + 2"` — текст, а не приклад
```
