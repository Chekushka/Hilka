Квадрат — 4 однакові пари «вперед + поворот». Замість чотирьох копій — **цикл**:

```notes
import turtle

for i in range(4):          # 4 сторони
    turtle.forward(100)
    turtle.right(90)
```

---

Кут правильного многокутника: `360 / n`.

```guess

print(360 / n)
-- *

--

```

---

Після запуску **повзунок** під полем показує малюнок крок за кроком.

```remember
`for i in range(4):` — повторити 4 рази
`360 / n` — кут для n сторін
```
