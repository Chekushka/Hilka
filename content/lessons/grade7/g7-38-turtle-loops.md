Квадрат — це чотири однакові пари «вперед + поворот». Замість того, щоб писати їх чотири рази, використай цикл:

```python
import turtle

for i in range(4):
    turtle.forward(100)
    turtle.right(90)
```

Для правильного многокутника з `n` сторонами кут повороту дорівнює `360 / n`: для трикутника — 120°, для п'ятикутника — 72°.

Після запуску можна переглянути малюнок крок за кроком — повзунок під полем показує, у якому порядку черепашка малювала.
