`if` всередині `if`: спершу перевірити одне, потім **уточнити**.

```notes
if x > 0:
    if y > 0:                   # лише коли x > 0
        print("перша чверть")   # вісім пробілів
    else:
        print("четверта чверть")
else:
    print("ліва половина")
```

---

```guess
x = 5
y = -2
if x > 0:
    if y > 0:
        print("перша чверть")
    else:
        print("четверта чверть")
else:
    print("ліва половина")
-- *
четверта чверть
--
перша чверть
--
ліва половина
-- чому
5 > 0 — заходимо всередину. −2 > 0 — ні, тож внутрішній `else`.
```

---

У `elif` **порядок важливий**: Python бере першу правдиву гілку.

```guess
score = 95
if score >= 75:
    print("добре")
elif score >= 90:
    print("відмінно")
else:
    print("спробуй ще")
-- *
добре
--
відмінно
--
добре
відмінно
-- чому
95 ≥ 75 — і все, до `>= 90` черга не дійшла. Найсуворіша умова — першою.
```

---

```remember
Внутрішній `if` — лише коли зовнішній правдивий.
`elif` — найсуворіша умова першою
```
