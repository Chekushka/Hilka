Всередині `if` можна написати ще один `if`. Так програма спершу перевіряє одне, а потім — уточнює:

```python
x = int(input())
y = int(input())
if x > 0:
    if y > 0:
        print("перша чверть")
    else:
        print("четверта чверть")
else:
    print("ліва половина")
```

Внутрішній `if` перевіряється лише тоді, коли зовнішня умова правдива. Відступи показують, що куди належить: у внутрішнього `if` їх **вісім**.

---

```guess
x = 5
y = -2
if x > 0:
    if y > 0:
        print("перша чверть")
    else:
        print("четверта чверть")
else:
    print("ліва половина")
-- *
четверта чверть
--
перша чверть
--
ліва половина
-- чому
5 > 0, тож програма заходить у зовнішній `if`. Там −2 > 0 — ні, і спрацьовує внутрішній `else`.
```

---

Коли варіантів багато, їх зручно перебрати через `elif` — **множинне розгалуження**. Порядок важливий: Python бере першу правдиву гілку.

```python
if score >= 90:
    print("відмінно")
elif score >= 75:
    print("добре")
else:
    print("спробуй ще")
```

---

А що буде, якщо переставити умови?

```guess
score = 95
if score >= 75:
    print("добре")
elif score >= 90:
    print("відмінно")
else:
    print("спробуй ще")
-- *
добре
--
відмінно
--
добре
відмінно
-- чому
95 ≥ 75 — правда, і Python бере цю гілку. До `score >= 90` черга не доходить. Тому найсуворішу умову ставлять першою.
```

```remember
Внутрішній `if` перевіряється, лише коли зовнішня умова правдива.
В `elif` порядок важливий: найсуворіша умова — перша.
```
