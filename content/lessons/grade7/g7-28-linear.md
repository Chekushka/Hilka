**Лінійний алгоритм** — це команди, які виконуються одна за одною, без пропусків і повторів. Зазвичай у ньому три кроки: зчитати дані, обчислити, вивести.

```python
length = int(input())
width = int(input())
area = length * width
print(area)
```

---

```guess
length = 4
width = 3
area = length * width
print(area)
-- *
12
--
7
--
length * width
-- чому
У змінних уже лежать 4 і 3, тож `area` стає 12. `print` виводить значення змінної, а не формулу, якою її порахували.
```

---

Цей урок — практика. Його можна пропустити, якщо бракує часу, але краще не варто: тут закріплюється все, що було досі.

```remember
Лінійний алгоритм: зчитати → обчислити → вивести.
`print(area)` виводить значення змінної, а не те, як його рахували.
```
