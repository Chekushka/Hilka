**Лінійний алгоритм** — це команди, які виконуються одна за одною, без пропусків і повторів. Зазвичай у ньому три кроки: зчитати дані, обчислити, вивести.

```python
length = int(input())
width = int(input())
area = length * width
print(area)
```

Цей урок — практика. Його можна пропустити, якщо бракує часу, але краще не варто: тут закріплюється все, що було досі.
