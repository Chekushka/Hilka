**Змінна** — це ім'я, під яким програма запам'ятовує значення. Знак `=` означає «поклади значення в змінну», а не «дорівнює».

```python
city = "Київ"
age = 13
print(city)
print(age)
```

---

Змінну можна перезаписати — тоді старе значення зникає:

```python
x = 5
x = 7
print(x)   # виведе 7
```

---

```guess
x = 5
x = x + 2
print(x)
--
5
-- *
7
--
x + 2
-- чому
Python спершу рахує праву частину: бере старе значення `x` (5), додає 2 — і кладе 7 назад у `x`.
```

---

Правила імен: латинські літери, цифри та `_`, але не можна починати з цифри і не можна пробілів. `my_score` — можна, `2score` — ні.

Щоб вставити змінну в текст, зручно використати f-рядок: `print(f"Я живу в місті {city}.")`

---

```guess
name = "Оля"
print(f"Привіт, {name}!")
--
Привіт, {name}!
-- *
Привіт, Оля!
--
Привіт, name!
-- чому
У f-рядку фігурні дужки — це місце, куди Python підставляє значення змінної.
```

---

```remember
`=` кладе значення в змінну: праворуч — що, ліворуч — куди.
Нове значення витирає старе.
`f"…{змінна}…"` підставляє значення змінної в текст.
```
