**Змінна** — ім'я, під яким програма запам'ятовує значення.

```notes
city = "Київ"   # у змінну city кладемо текст
age = 13        # а в age — число
print(city)     # виводимо, що лежить у city
```

---

Нове значення **витирає** старе:

```notes
x = 5
x = 7      # 5 зникло
print(x)   # виведе 7
```

---

```guess
x = 5
x = x + 2
print(x)
--
5
-- *
7
--
x + 2
-- чому
Спершу права частина: старе `x` (5) плюс 2. Результат 7 кладеться назад у `x`.
```

---

Імена змінних:

- `my_score` — можна: латинські літери, цифри, `_`
- `2score` — не можна: починається з цифри
- `my score` — не можна: пробіл

---

```guess
name = "Оля"
print(f"Привіт, {name}!")
--
Привіт, {name}!
-- *
Привіт, Оля!
--
Привіт, name!
-- чому
У f-рядку `{name}` замінюється значенням змінної.
```

---

```remember
`x = 5` — покласти 5 у змінну x
`x = x + 2` — взяти старе x і додати 2
`f"{x}"` — вставити значення x у текст
```
