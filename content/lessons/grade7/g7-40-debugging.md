Помилки бувають двох видів:

- **Синтаксичні** — Python не розуміє запис: забута двокрапка, дужка, неправильний відступ. Програма навіть не запускається, і Hilka покаже рядок.
- **Логічні** — програма працює, але робить не те. Їх доводиться шукати самому.

---

Ця програма мала порахувати середнє двох чисел. Вона запускається без помилок — але що вона виведе?

```guess
a = 4
b = 6
print("Середнє:", a + b / 2)
-- *
Середнє: 7.0
--
Середнє: 5.0
--
Середнє: 5
-- чому
Це логічна помилка: ділення виконується раніше за додавання, тож виходить 4 + 3.0 = 7.0. Правильно — `(a + b) / 2`.
```

---

Як шукати логічну помилку:

1. Запусти програму і порівняй результат із ціллю.
2. Пройди малюнок крок за кроком повзунком під полем — де саме черепашка пішла не туди?
3. Знайди рядок, який за це відповідає, і виправ одну річ за раз.

```python
import turtle

for i in range(4):
    turtle.forward(100)
    turtle.right(90)
```

```remember
Синтаксична помилка — Python не розуміє запис. Логічна — програма робить не те.
Порівняй результат із ціллю і виправляй одну річ за раз.
```
