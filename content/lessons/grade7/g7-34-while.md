Цикл `while` повторює команди, **поки** умова правдива:

```python
n = 1
while n < 100:
    n = n * 2
print(n)   # 128
```

Кожного разу Python перевіряє умову. Щойно вона стає хибною — цикл закінчується, і програма йде далі.

---

```guess
n = 1
while n < 10:
    n = n + 3
print(n)
-- *
10
--
9
--
7
-- чому
`n` стає 4, 7, 10. Коли `n` дорівнює 10, умова `n < 10` уже хибна — цикл зупиняється, і `print` виводить 10.
```

---

Важливо: всередині циклу щось має змінюватися, інакше умова ніколи не стане хибною, і цикл не закінчиться.

`while` зручний, коли заздалегідь невідомо, скільки буде повторів — наприклад, «зчитуй числа, поки не введуть 0».

```guess
count = 0
while count < 3:
    print("ще")
    count = count + 1
-- *
ще
ще
ще
--
ще
ще
--
ще
ще
ще
ще
-- чому
`count` буває 0, 1 і 2 — три повтори. Коли він стає 3, умова `count < 3` хибна.
```

```remember
`while` повторює команди, поки умова правдива.
Усередині має щось змінюватися, інакше цикл не закінчиться.
```
