`while` повторює, **поки** умова правдива:

```notes
n = 1
while n < 100:    # перевірка перед кожним повтором
    n = n * 2     # щось має змінюватися!
print(n)          # після циклу
```

---

```guess
n = 1
while n < 10:
    n = n + 3
print(n)
-- *
10
--
9
--
7
-- чому
`n`: 4, 7, 10. На 10 умова `n < 10` хибна — цикл стоп.
```

---

Якщо в циклі **нічого не змінюється**, він ніколи не закінчиться.

```guess
count = 0
while count < 3:
    print("ще")
    count = count + 1
-- *
ще
ще
ще
--
ще
ще
--
ще
ще
ще
ще
-- чому
`count`: 0, 1, 2 — три повтори. На 3 умова хибна.
```

---

```remember
`while умова:` — повторювати, поки правда
Усередині щось має змінюватися.
```
