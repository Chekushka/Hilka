Цикл `while` повторює команди, **поки** умова правдива:

```python
n = 1
while n < 100:
    n = n * 2
print(n)   # 128
```

Кожного разу Python перевіряє умову. Щойно вона стає хибною — цикл закінчується, і програма йде далі.

Важливо: всередині циклу щось має змінюватися, інакше умова ніколи не стане хибною, і цикл не закінчиться.

`while` зручний, коли заздалегідь невідомо, скільки буде повторів — наприклад, «зчитуй числа, поки не введуть 0».
