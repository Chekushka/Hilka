Python рахує:

- `+` `-` `*` — плюс, мінус, множення
- `/` — ділення, завжди дробове: `7 / 2` → `3.5`
- `//` — націло: `7 // 2` → `3`
- `%` — остача: `7 % 2` → `1`

---

```guess
print(17 // 5)
print(17 % 5)
-- *
3
2
--
3.4
2
--
2
3
-- чому
5 вміщається в 17 тричі (`//`), і ще 2 лишається (`%`).
```

---

Як у математиці: **множення раніше** за додавання. Дужки змінюють порядок.

```notes
print(2 + 3 * 4)     # спершу 3 * 4
print((2 + 3) * 4)   # спершу дужки
```

---

```guess
print(10 - 2 * 3)
--
24
-- *
4
--
6
-- чому
Спершу 2 * 3 = 6, потім 10 - 6 = 4.
```

---

`input()` дає **текст**. Для чисел — `int()`:

```python
a = int(input())
b = int(input())
print(a * b)
```

```remember
`//` — ділення націло
`%` — остача від ділення
`int(input())` — зчитати ціле число
Множення й ділення — раніше за додавання.
```
