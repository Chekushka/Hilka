Python уміє рахувати:

- `+` додавання, `-` віднімання, `*` множення
- `/` ділення (результат завжди дробовий: `7 / 2` дає `3.5`)
- `//` ділення націло (`7 // 2` дає `3`)
- `%` остача від ділення (`7 % 2` дає `1`)

---

```guess
print(17 // 5)
print(17 % 5)
-- *
3
2
--
3.4
2
--
2
3
-- чому
У 17 число 5 вміщається 3 рази (це `//`), і ще 2 лишається (це `%`).
```

---

Як і в математиці, множення й ділення виконуються раніше за додавання. Дужки змінюють порядок:

```python
print(2 + 3 * 4)     # 14
print((2 + 3) * 4)   # 20
```

```guess
print(10 - 2 * 3)
--
24
-- *
4
--
6
-- чому
Спершу множення: 2 * 3 = 6. Потім віднімання: 10 - 6 = 4. Щоб відняти першим, потрібні дужки: `(10 - 2) * 3`.
```

---

Число від користувача зчитує `input()`, але воно приходить як **текст**. Щоб рахувати, перетвори його на число:

```python
a = int(input())
b = int(input())
print(a * b)
```

```remember
`//` — ділення націло, `%` — остача від ділення.
Множення й ділення виконуються раніше за додавання; дужки змінюють порядок.
`input()` дає текст — для числа пиши `int(input())`.
```
