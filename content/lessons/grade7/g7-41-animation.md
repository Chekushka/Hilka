**Анімація** — кадри, що швидко змінюють один одного. Кожен — трохи інший.

```notes
import turtle

for i in range(5):
    turtle.clear()            # стерти старий кадр
    turtle.penup()            # підняти олівець
    turtle.goto(i * 30, 0)    # кожен кадр — правіше
    turtle.pendown()
    for side in range(4):     # намалювати квадрат
        turtle.forward(40)
        turtle.left(90)
```

`goto(x, y)` — перенести черепашку
