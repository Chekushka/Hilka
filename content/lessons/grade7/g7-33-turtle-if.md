`i % 2` — остача від ділення на 2: **0** для парних, **1** для непарних.

---

Умова в циклі — і кроки **чергуються**:

```notes
import turtle

for i in range(4):
    if i % 2 == 0:              # парний крок
        turtle.forward(100)     # довга сторона
    else:
        turtle.forward(50)      # коротка
    turtle.left(90)
```

---

```remember
`i % 2 == 0` — i парне
`i % 2 == 1` — i непарне
```
