Умова разом із черепашкою дозволяє малювати фігури, в яких кроки чергуються.

Остача від ділення `i % 2` дорівнює `0` для парних чисел і `1` для непарних:

```guess
for i in range(4):
    print(i % 2)
-- *
0
1
0
1
--
1
2
3
4
--
0
0
1
1
-- чому
`i` по черзі дорівнює 0, 1, 2, 3, а остача від ділення на 2 — 0, 1, 0, 1. Парні дають 0, непарні — 1.
```

---

```python
import turtle

for i in range(4):
    if i % 2 == 0:
        turtle.forward(100)
    else:
        turtle.forward(50)
    turtle.left(90)
```

Ця програма малює прямокутник: на парних кроках довга сторона, на непарних — коротка.

Додаткові завдання — для тих, хто хоче спробувати `elif` з трьома варіантами.

```remember
`i % 2 == 0` — правда, коли `i` парне.
Умову можна поставити всередину циклу, щоб кроки чергувалися.
```
