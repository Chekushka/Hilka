**Програма** — це список команд. Python виконує їх по черзі, **згори донизу**.

```notes
print("Привіт!")             # перша команда
print("Мене звати Python")   # друга — з нового рядка
```

---

```guess
print("раз")
print("два")
-- *
раз
два
--
раз два
--
"раз"
"два"
-- чому
Кожен `print()` — новий рядок. Лапки не виводяться: вони лише показують, де текст.
```

---

Дві кнопки під редактором:

- `Запустити` — подивитися, що робить програма
- `Здати` — коли завдання виконано

```remember
`print()` — виводить те, що в дужках
`"текст"` — текст пишуть у лапках
Команди виконуються згори донизу.
```
