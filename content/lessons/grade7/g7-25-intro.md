Програма — це список команд для комп'ютера. Python виконує їх по черзі, згори донизу.

Перша команда, яку варто знати, — `print()`. Вона **виводить** на екран те, що написано в дужках:

```python
print("Привіт!")
print("Мене звати Python")
```

---

Текст береться в лапки. Кожен `print()` виводить окремий рядок.

```guess
print("раз")
print("два")
-- *
раз
два
--
раз два
--
"раз"
"два"
-- чому
Кожен `print()` починає новий рядок, а лапки не виводяться — вони лише показують Python, де починається і закінчується текст.
```

---

Натисни **Запустити**, щоб побачити, що зробить твоя програма, і **Здати**, коли вважаєш, що завдання виконано.

```remember
Python виконує команди по черзі, згори донизу.
`print()` виводить те, що в дужках, — кожен з нового рядка.
Текст пишуть у лапках, але на екран лапки не виводяться.
```
