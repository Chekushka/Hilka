Практика з розгалуженням. Нагадування:

```python
if умова:
    ...
elif інша_умова:
    ...
else:
    ...
```

Перевіряється лише перша правдива гілка — решта пропускаються. Не забувай про двокрапку і відступи.

---

```guess
score = 75
if score >= 90:
    print("відмінно")
elif score >= 60:
    print("добре")
else:
    print("спробуй ще")

-- чому
75 ≥ 90 — ні. 75 ≥ 60 — так, тож «добре». Гілка `else` після цього вже пропускається.
```

---

Урок можна пропустити, але краще не варто.

```remember
Перевіряється лише перша правдива гілка — решта пропускаються.
Не забувай двокрапку після умови і відступ усередині.
```
