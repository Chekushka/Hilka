Будь-яку фігуру з прямих ліній черепашка малює так: пройти сторону, повернути, пройти наступну.

У прямокутнику протилежні сторони однакові, а всі кути — по 90°:

```python
import turtle

turtle.forward(120)
turtle.left(90)
turtle.forward(60)
turtle.left(90)
turtle.forward(120)
turtle.left(90)
turtle.forward(60)
```

Цей урок — практика: можна пропустити, але краще не варто. Додаткове завдання — для тих, хто впорався швидше.
