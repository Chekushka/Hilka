Фігура з прямих: **сторона → поворот → сторона → …**

У прямокутнику протилежні сторони однакові, кути — по 90°:

```notes
import turtle

turtle.forward(120)   # довга сторона
turtle.left(90)
turtle.forward(60)    # коротка
turtle.left(90)
turtle.forward(120)   # знову довга
turtle.left(90)
turtle.forward(60)
```
