Іноді програма має вибирати, що робити. Для цього є умовний оператор `if`:

```python
x = int(input())
if x > 0:
    print("додатне")
else:
    print("не додатне")
```

Рядки всередині `if` та `else` пишуться з **відступом** — чотири пробіли. Саме відступ показує, що належить до умови. Після умови обов'язкова двокрапка `:`.

---

Порівняння: `>`, `<`, `>=`, `<=`, `==` (дорівнює — два знаки!), `!=` (не дорівнює).

```guess
x = 5
if x > 3:
    print("більше")
else:
    print("не більше")
print("кінець")
-- *
більше
кінець
--
більше
--
не більше
кінець
-- чому
5 > 3 — правда, тож виконується гілка `if`. А `print("кінець")` написано без відступу: він не належить до умови і виконується завжди.
```

---

Коли варіантів більше двох, допомагає `elif`:

```python
if x > 0:
    print("додатне")
elif x < 0:
    print("від'ємне")
else:
    print("нуль")
```

Дві умови разом поєднує `and`: `if x >= 1 and x <= 10:`

---

```guess
x = 10
if x > 5:
    print("A")
elif x > 8:
    print("B")
else:
    print("C")
-- *
A
--
B
--
A
B
-- чому
Python перевіряє умови згори донизу і бере першу правдиву: 10 > 5 — правда, тож виводиться A. Другу умову вже ніхто не перевіряє, хоч вона теж правдива.
```

```remember
Після умови — двокрапка, усередині — відступ у 4 пробіли.
`==` порівнює, а `=` кладе значення в змінну.
З `if … elif … else` виконується лише перша правдива гілка.
```
