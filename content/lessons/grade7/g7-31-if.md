`if` дає програмі **вибір**:

```notes
x = int(input())
if x > 0:                 # двокрапка обов'язкова
    print("додатне")      # відступ — 4 пробіли
else:
    print("не додатне")
```

---

Порівняння:

- `>` `<` — більше, менше
- `>=` `<=` — більше або дорівнює, менше або дорівнює
- `==` — дорівнює (два знаки!)
- `!=` — не дорівнює

---

Більше двох варіантів — `elif`:

```python
if x > 0:
    print("додатне")
elif x < 0:
    print("від'ємне")
else:
    print("нуль")
```

```remember
`if умова:` — двокрапка, далі відступ
`==` — порівняти, а `=` — покласти
`elif` — ще один варіант
Виконується лише перша правдива гілка.
```
