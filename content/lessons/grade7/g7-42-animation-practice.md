Практика з динамічною графікою. Кадр зазвичай будується так:

1. `turtle.clear()` — стерти попередній кадр.
2. Підняти олівець і перейти в потрібну точку: `penup()`, `goto(x, y)`, `pendown()`.
3. За потреби задати напрям: `turtle.setheading(кут)`.
4. Намалювати фігуру.

---

```guess
x = 0
for frame in range(3):
    x = x + 50
    print(x)
-- *
50
100
150
--
0
50
100
--
150
-- чому
`x` збільшується ще до виведення, тож перше число — уже 50. А `print` стоїть усередині циклу, тому виводить на кожному кадрі.
```

---

Урок можна пропустити, але краще не варто.

```remember
Кадр: стерти → перейти в точку → намалювати.
Змінна, яка росте в циклі, зсуває кожен наступний кадр.
```
