**Рядок** — теж послідовність, як список, але з символів:

```notes
word = "програма"
print(word[0])       # п — нумерація з 0
print(word[-1])      # а — остання
print(len(word))     # 8 — довжина
```

---

**Зріз** — шматок рядка `[початок:кінець]`, кінець не входить:

```notes
word = "програма"
print(word[0:3])     # про
print(word[3:])      # грама — до кінця
print(word[::-1])    # амаргорп — задом наперед
```

---

```guess
s = "Україна"
print(s[1:4])
-- *
кра
--
Укр
--
краї
-- чому
Номери 1, 2, 3 — «к», «р», «а». Номер 4 уже не входить.
```

---

`for` іде по літерах рядка:

```notes
count = 0
for ch in "молоко":
    if ch == "о":
        count = count + 1
print(count)          # 3
```

---

```guess
result = ""
for ch in "кіт":
    result = ch + result
print(result)
-- *
тік
--
кіт
--
ккііт
-- чому
Кожна нова літера стає **спереду**: «к», «ік», «тік».
```

---

Рядок **не можна змінити** на місці — лише зібрати новий:

```notes
word = "київ"
# word[0] = "К"     — TypeError!
word = word[0].upper() + word[1:]   # Київ
```

---

```remember
`s[0]` — перший символ, `s[-1]` — останній
`s[a:b]` — зріз, `b` не входить; `s[::-1]` — навпаки
Рядок не змінюють — збирають новий
```
