Програма майже завжди йде в три кроки:

```notes
a = int(input())     # 1. введення
b = int(input())
area = a * b         # 2. обчислення
print(area)          # 3. виведення
```

---

Усе, що ти вже знаєш, у одній програмі:

```notes
total = 0                  # змінна
for i in range(1, 6):      # цикл for
    if i % 2 == 0:         # умова
        total = total + i
print(total)               # виведення
```

---

```guess
total = 0
for i in range(1, 6):
    if i % 2 == 0:
        total = total + i
print(total)
-- *
6
--
15
--
2
4
--
9
-- чому
Парні серед 1…5 — лише 2 і 4. Разом 6. `print` без відступу — один раз, після циклу.
```

---

Коли кількість повторень невідома — `while`:

```flow
поки x != 0
повтор: count = count + 1
повтор: x = int(input())
далі: print(count)
```

---

```guess
x = 20
steps = 0
while x > 1:
    x = x // 2
    steps = steps + 1
print(steps)
-- *
4
--
5
--
10
--
20
-- чому
20 → 10 → 5 → 2 → 1: чотири ділення, і умова `x > 1` стала хибною.
```

---

```remember
Введення → обчислення → виведення
`input()` дає текст — для числа потрібен `int()`
`for` — відома кількість повторень, `while` — поки умова правдива
```
