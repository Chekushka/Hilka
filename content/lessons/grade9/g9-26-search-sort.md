Шукати в списку — готовими інструментами:

```notes
t = [3, 9, 4, 9]
print(9 in t)        # True — чи є таке значення
print(t.index(9))    # 1 — номер першого входження
print(t.count(9))    # 2 — скільки разів трапляється
print(max(t), min(t), sum(t))   # 9 3 25
```

---

```guess
t = [5, 1, 5, 8]
print(t.index(5), t.count(5), max(t))
-- *
0 2 8
--
1 2 8
--
0 1 8
--
2 0 8
-- чому
Перша п'ятірка стоїть на місці 0, п'ятірок дві, найбільше — 8.
```

Пошук найбільшого вручну — як у 8 класі:

```notes
biggest = nums[0]          # не 0, а перший елемент!
for x in nums:
    if x > biggest:
        biggest = x
```

**Сортування.** `sort()` змінює сам список, `sorted()` робить новий:

```notes
a = [5, 2, 8]
b = sorted(a)           # b = [2, 5, 8], a не змінився
a.sort()                # тепер a = [2, 5, 8]
a.sort(reverse=True)    # від більшого: [8, 5, 2]
```

---

```guess
a = [3, 1, 2]
b = sorted(a)
print(a)
print(b)
-- *
[3, 1, 2]
[1, 2, 3]
--
[1, 2, 3]
[1, 2, 3]
--
[3, 1, 2]
[3, 1, 2]
-- чому
`sorted` повертає новий список, а `a` залишається, як був.
```

---

```guess
a = [3, 1, 2]
a = a.sort()
print(a)
-- *
None
--
[1, 2, 3]
--
[3, 1, 2]
-- чому
`sort()` нічого не повертає. Записавши результат у `a`, ми втратили список.
```

---

```remember
`x in nums` — чи є; `nums.index(x)` — де
`nums.sort()` — сортує сам список, нічого не повертає
`sorted(nums)` — новий відсортований список
`reverse=True` — від більшого до меншого
```
