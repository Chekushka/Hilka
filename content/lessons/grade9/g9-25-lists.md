**Список** — багато значень в одній змінній:

```notes
marks = [10, 7, 12]      # квадратні дужки, через кому
print(marks[0])          # 10 — нумерація з 0
print(marks[-1])         # 12 — останній
print(len(marks))        # 3 — скільки елементів
```

---

```guess
pets = ["кіт", "пес", "рибка"]
print(pets[1])
-- *
пес
--
кіт
--
рибка
-- чому
Номери починаються з 0: `pets[0]` — кіт, `pets[1]` — пес.
```

---

Список можна змінювати:

```notes
nums = [4, 8]
nums.append(15)     # додати в кінець → [4, 8, 15]
nums.remove(8)      # прибрати значення 8 → [4, 15]
nums.pop()          # прибрати останній → [4]
nums[0] = 100       # замінити елемент → [100]
```

---

```guess
a = [1, 2]
a.append(3)
a.append(4)
a.pop()
print(a, len(a))
-- *
[1, 2, 3] 3
--
[1, 2, 3, 4] 4
--
[2, 3, 4] 3
-- чому
Два `append` дають `[1, 2, 3, 4]`, а `pop()` прибирає останнє — 4.
```

---

`for` проходить по списку — **кожен елемент по черзі**:

```notes
prices = [12, 30, 8]
total = 0
for p in prices:        # p = 12, потім 30, потім 8
    total = total + p
print(total)            # 50
```

---

Список із введених чисел:

```notes
n = int(input())
nums = []                       # порожній список
for i in range(n):
    nums.append(int(input()))   # кожне число — в кінець
```

---

```guess
nums = [3, 6, 2, 9]
count = 0
for x in nums:
    if x > 4:
        count = count + 1
print(count)
-- *
2
--
4
--
15
--
6
9
-- чому
Більші за 4 — лише 6 і 9. Лічильник збільшився двічі.
```

---

```remember
`nums[0]` — перший, `nums[-1]` — останній
`append` — додати в кінець, `len` — довжина
`for x in nums:` — по кожному елементу
```
