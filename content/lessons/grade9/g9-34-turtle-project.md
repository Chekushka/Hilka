Проєкт із черепашкою: **дані в списку — малюнок у циклі**.

```notes
import turtle
for side in [100, 50, 100, 50]:   # сторони — зі списку
    turtle.forward(side)
    turtle.left(90)               # прямокутник
```

---

Цикл у циклі: для кожного n — n-кутник.

```notes
for n in [3, 4, 5]:
    for i in range(n):
        turtle.forward(60)
        turtle.left(360 / n)     # кут залежить від n
```


---

Перейти, не малюючи, — `penup` і `goto`:

```notes
turtle.penup()            # перо вгору — слід не лишається
turtle.goto(-50, -50)     # просто в точку (x, y)
turtle.pendown()          # перо вниз — далі малюємо
```

---

Колір теж можна брати зі списку:

```notes
colors = ["red", "green", "blue"]
for c in colors:
    turtle.color(c)        # кожна фігура — свого кольору
    turtle.forward(50)
    turtle.left(120)
```

---

```remember
Дані — у список, малювання — у цикл по списку
Кут правильного n-кутника — `360 / n`
`penup()` → `goto(x, y)` → `pendown()` — перехід без сліду
```
