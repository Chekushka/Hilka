Список можна не вводити руками, а **згенерувати**:

```notes
a = list(range(5))          # [0, 1, 2, 3, 4]
b = list(range(1, 6))       # [1, 2, 3, 4, 5]
c = list(range(0, 20, 5))   # [0, 5, 10, 15] — крок 5
```

---

```guess
print(list(range(3, 10, 2)))
-- *
[3, 5, 7, 9]
--
[3, 5, 7, 9, 11]
--
[3, 4, 5, 6, 7, 8, 9]
-- чому
Від 3 з кроком 2, поки менше 10: 3, 5, 7, 9.
```

---

Або збирати в циклі за правилом:

```notes
squares = []
for i in range(1, 5):
    squares.append(i * i)    # [1, 4, 9, 16]
```

Те саме коротко: `[i * i for i in range(1, 5)]`

---

```guess
print([x + 1 for x in range(3)])
-- *
[1, 2, 3]
--
[0, 1, 2]
--
[1, 1, 1]
-- чому
x пробігає 0, 1, 2 — і до кожного додається 1.
```

---

Випадкові числа — модуль `random`:

```notes
import random
nums = []
for i in range(10):
    nums.append(random.randint(1, 100))   # від 1 до 100
print(nums)        # щоразу інший список
```

---

```remember
`list(range(a, b, крок))` — готовий список чисел
`random.randint(1, 100)` — випадкове ціле, обидві межі входять
Випадковий список щоразу інший — перевіряй його властивості, а не значення
```
