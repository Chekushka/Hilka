**Шифр Цезаря**: кожну літеру заміняємо тією, що стоїть на `k` позицій далі в абетці.

Зсув 1: а → б, б → в, …, я → а.

---

Абетку зручно тримати в рядку:

```notes
abc = "абвгґдеєжзиіїйклмнопрстуфхцчшщьюя"
print(len(abc))         # 33 літери
print(abc.find("к"))    # 14 — номер літери
print(abc[15])          # л — літера за номером
```

---

```guess
abc = "абвгґдеєжзиіїйклмнопрстуфхцчшщьюя"
i = abc.find("к")
print(abc[i + 1])
-- *
л
--
к
--
й
-- чому
Номер «к» — 14, а 15 — це «л». Так і шифрують зі зсувом 1.
```

---

Що робити після «я»? Остача від ділення повертає на початок:

```notes
abc = "абвгґдеєжзиіїйклмнопрстуфхцчшщьюя"
i = abc.find("я")          # 32
print(abc[(i + 2) % 33])   # 34 % 33 = 1 → б
```

---

```guess
print(35 % 33, 33 % 33, 5 % 33)
-- *
2 0 5
--
2 1 5
--
35 33 5
-- чому
`%` — остача: 35 = 33 + 2, 33 ділиться націло, 5 менше за 33.
```

---

Шифруємо цілий рядок — збираємо результат по літері:

```notes
result = ""
for ch in text:
    if ch in abc:                                   # літера?
        i = abc.find(ch)
        result = result + abc[(i + k) % len(abc)]   # зсув
    else:
        result = result + ch                        # пробіл, кома — як є
print(result)
```

---

Повідомлення з параметрами — **f-рядок**:

```guess
name = "Оля"
k = 3
print(f"{name}, твій ключ: {k}")
-- *
Оля, твій ключ: 3
--
{name}, твій ключ: {k}
--
name, твій ключ: k
-- чому
`f` перед лапками — і Python підставляє значення змінних у `{ }`.
```

---

```remember
`abc.find(ch)` — номер літери, `abc[i]` — літера за номером
`(i + k) % len(abc)` — зсув по колу
Розшифрувати — зсунути назад: `i - k`
```
