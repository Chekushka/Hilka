**Тест** — це вхідні дані й очікуваний результат. Програма правильна, лише коли проходить усі тести.

---

Тестів має бути стільки, щоб пройти **кожну гілку**:

```notes
if x > 0:
    print("додатне")     # тест: 5
elif x < 0:
    print("від'ємне")    # тест: -5
else:
    print("нуль")        # тест: 0
```

---

Помилки ховаються на **межах**. Знижка до 12 років включно — перевір 12 і 13:

```guess
age = 12
if age < 12:
    print("дитячий")
else:
    print("дорослий")
-- *
дорослий
--
дитячий
-- чому
12 < 12 — хибне. Тест на межі показав помилку: тут потрібне `<=`.
```

---

**Таблиця тестування**:

```
Ввели   Має бути   Вийшло
5       дитячий    дитячий
12      дитячий    дорослий   ✗
13      дорослий   дорослий
```

Hilka робить таку таблицю сама — це список тестів під завданням.

---

Ще кілька особливих тестів: **від'ємні** числа, **одне** число, **усі однакові**, **порожній** рядок.

```guess
nums = [-4, -2, -9]
biggest = 0
for x in nums:
    if x > biggest:
        biggest = x
print(biggest)
-- *
0
--
-2
--
-9
-- чому
Помилка: найбільше почали з 0. Тест «усі від'ємні» це виявив — правильно було б `-2`.
```

---

```remember
Тест = вхідні дані + очікуваний результат
По тесту на кожну гілку
Перевіряй межі (12 і 13), від'ємні, одне значення, порожнє
```
