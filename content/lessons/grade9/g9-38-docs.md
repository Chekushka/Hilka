Програму читають люди — і ти сам через місяць. Для них — **коментарі** й **документація**.

---

Коментар починається з `#`. Python його пропускає:

```notes
price = price * 0.8   # знижка 20% для учнів
# print(price)        — тимчасово вимкнений рядок
```

Добрий коментар пояснює **навіщо**, а не переказує код.

---

```guess
x = 3
# x = x * 100
x = x * 2  # подвоюємо
print(x)
-- *
6
--
300
--
600
-- чому
Рядок із `#` на початку не виконується, тож множення на 100 не було.
```

---

**Документація** проєкту (README) — коротко:

- що робить програма;
- як її запустити;
- приклад: що ввести і що вийде;
- таблиця тестів.

---

Чи правильна програма? Пройди тести з таблиці й порівняй **очікуване** з **фактичним**. Хоч один не збігся — шукай помилку.

---

```remember
`#` — коментар, Python його не виконує
Коментар пояснює навіщо
README: що робить, як запустити, приклад, тести
```
