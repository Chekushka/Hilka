Turtle stub vs CPython signatures (file delivery)

    
File delivery means turtle code written in Hilka has to run unchanged in IDLE,
      on real CPython's turtle module — not this stub. This page cannot call real
      CPython, so it renders a comparison table instead of running one: Hilka's side is
      transcribed straight from lib/runner/modules/turtle.ts; the CPython side from
      the documented stdlib API. Confirm each row against IDLE on this machine and record what
      you find — that confirmation, not this table by itself, is what answers check 7.
